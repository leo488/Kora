# Archive: work we made and did not use

Nothing in this folder is shown on the site. The live images are in `src/assets/`.
Each zip opens into named folders. Large 4K PNG masters were saved here as full-resolution
JPG (quality 90 to 95) so the zips fit in the repo; the lossless PNGs stay in the project
Library and in the Magnific projects.

| Zip | What is inside |
|---|---|
| `ipaybtc/ipaybtc-unused-site-images.zip` | Images that were on the iPayBTC page in earlier rounds and were removed: Figma frames (`figma/`), v3 app screens (`v3/`), first 3D set (`ipaybtc3d/`), stock scenes, illustrations |
| `ipaybtc/ipaybtc-working-files.zip` | Shot list, animation summary, case-study art, first cut, looks, storyboard, logo animation, the v4 app package (screens, coins, tokens, motion) |
| `refreeg/refreeg-1-first-round-rejected.zip` | Round 1 (rejected): 7 mockups and their plates |
| `refreeg/refreeg-2-blank-scenes-4k.zip` | Round 2: the blank 4K scenes from Magnific, retakes (`-v2`), billboard and tote artwork sources |
| `refreeg/refreeg-3-finished-plates-and-sources.zip` | Finished plates at full size, plus the scripts and HTML that built them (`gen.py`, `comp.py`, `grade.py`, `plates.html`) |
| `refreeg/refreeg-4-bento-film-brand-refs.zip` | Final bento sources, launch film and its frames, Figma exports, brand book pages, the plan, the reference layouts |
| `3projects/3projects-frames-and-previews.zip` | The 13 proposal frames and site previews |
| `tagmi/tagmi-working-files.zip` | Tagmi plate |

Not included: client fonts and Leo's own uploads (`.fig` files, guideline and pitch zips). They are in the project Library.
